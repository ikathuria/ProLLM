# Handoff template

```markdown
# Handoff: <date> · <short task name>

**Goal:** <what the user is trying to do, 1–2 sentences>
**Status:** <one line: where things stand>

## Next step
<single concrete action> → verify by <command / check>

## Done this session
- <item> (<commit hash or file>)

## Decisions
- <decision>: <why>. Rejected: <alternative> (<why not>)

## Open threads
- <unfinished item / running job: PID, log path, ETA / question for the user>

## Gotchas
- <what went wrong>: <the fix or workaround>

## Read first
- `<path>`: <what's in it>

## Uncommitted
<`git status --short` output, or "clean">
```

Rules: no narrative of the session, no restating the plan (link to PLAN.md instead), and
every path must exist.
