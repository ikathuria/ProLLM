# AI Slop Patterns — Ban List

Each item: the default pattern and what to do instead. These ban *unthinking defaults*, not
effects — every "instead" should be a bolder, more specific choice, never just deletion.

## Color
| Pattern | Instead |
|---|---|
| Indigo/violet primary (`#6366f1`, `violet-500`) by default | Derive the accent from the reference; muted or unexpected hues (ochre, oxblood, forest, signal orange) |
| Purple→blue/pink gradient backgrounds, gradient text | Bold flat color-blocking, or a gradient with a reason (brand hues, grain, mesh tied to the product) |
| Blurred glowing blobs / aurora behind hero | Real product screenshot, custom illustration/pattern, or giant typography |
| Pure `#000` on pure `#fff`, or gray-on-gray low contrast | Tinted neutrals (warm or cool), checked for contrast |
| Dark mode = slate-900 + neon accents | Designed dark palette with reduced-saturation accent |

## Layout
| Pattern | Instead |
|---|---|
| Hero: centered H1 + subtitle + two buttons + screenshot | Asymmetric hero, left-aligned, or lead with the product itself |
| 3 identical icon-cards "Features" grid | Varied layout: list with detail, alternating rows, a table, a single deep feature |
| Every section `py-24`, same max-width | Deliberate rhythm — tight and loose sections, some full-bleed |
| Cards inside cards inside cards | Flatten; use spacing and dividers |
| Bento grid for everything | Only when content actually has different sizes |

## Components & detail
| Pattern | Instead |
|---|---|
| `rounded-2xl shadow-xl` on all surfaces | One radius scale (e.g. 4/8), shadow only on floating layers |
| Glassmorphism / backdrop-blur panels | Solid surfaces unless layered over imagery |
| Emoji as icons ✨🚀 | Custom marks/illustrations, or a consistent icon set styled to the brand (weight, color, container) |
| Pill badges "New ✨" above every H1 | Remove |
| Fake testimonials with stock avatars | Real quotes or omit |
| Stats row "10k+ users · 99.9% uptime · 24/7" | Only true, specific numbers |

## Type
| Pattern | Instead |
|---|---|
| Inter/system for everything, one weight | Distinct display + text pairing, 2–3 weights, a real type scale |
| Huge bold H1, tiny gray body | Controlled scale (e.g. 1.25 ratio), readable body 16–18px, 60–75ch line length |
| Title Case Everywhere | Sentence case |

## Motion
| Pattern | Instead |
|---|---|
| Fade-up on every section scroll | A few crafted moments: hero entrance, staggered reveals, delightful micro-interactions |
| `hover:scale-105` on cards and buttons | Hover with character: color fill sweep, offset-shadow press, underline draw, icon nudge |

## Sterile slop (the overcorrection)
| Pattern | Instead |
|---|---|
| Beige/off-white page, one serif, gray text, nothing else | Commit to color: full-bleed colored sections, tinted surfaces, a second accent |
| Accent color used only on a single button | Use the palette on surfaces, illustrations, highlights, data |
| No imagery at all — just text and hairlines | Screenshots, illustration, pattern, texture, photography with a treatment |
| Uniformly small, polite type scale | At least one dramatic jump — display type that dominates |
| Zero motion, zero hover personality | Two or three crafted interactions |
| Everything monochrome "for taste" | Monochrome only if the brief chose it, and then push contrast hard |
| Copy stripped to neutral, voiceless statements | Specific *and* with voice — a little wit or opinion |

## Copy
Ban: "Unlock", "Elevate", "Seamless(ly)", "Supercharge", "Revolutionize", "Harness the power",
"Your all-in-one", "Built for the modern…", "Say goodbye to…". Write what the product does,
for whom, concretely.
