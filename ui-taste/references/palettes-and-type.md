# Starting Points (adapt, don't copy verbatim)

## Type pairings (all on Google Fonts)
| Feel | Display | Text |
|---|---|---|
| Editorial / literary | Fraunces or Instrument Serif | Source Serif 4 or Inter |
| Swiss / technical | Inter Tight (tight tracking, heavy) | Inter |
| Engineering tool | JetBrains Mono / IBM Plex Mono (labels, numbers) | IBM Plex Sans |
| Warm product | Bricolage Grotesque | DM Sans |
| Brutalist | Space Grotesk / Archivo Black | Archivo |
| Luxury / calm | Cormorant Garamond | Manrope |

Use tabular numerals (`font-variant-numeric: tabular-nums`) in tables and dashboards.
